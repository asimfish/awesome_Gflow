# N019 · FlowRL: Matching Reward Distributions for LLM Reasoning

> 发表：ICLR 2026 · 链接：https://arxiv.org/abs/2509.15207

## 一句话
FlowRL通过匹配奖励分布而非最大化奖励来优化策略模型，从而提高大语言模型在推理任务中的多样性和泛化能力。

## 问题与动机
传统的强化学习方法如PPO和GRPO倾向于优化主导的奖励模式，这会导致模式坍缩，忽略其他有效的推理路径。这种做法减少了生成推理路径的多样性，并降低了对较少出现但有效逻辑结果的泛化能力。因此，需要一种新的方法来促进多样性的探索，防止收敛到主导解决方案模式。

## 方法核心
### 核心思想
FlowRL的核心思想是将标量奖励转换成一个目标分布，并最小化策略与该目标分布之间的逆KL散度。具体步骤如下：

1. **引入可学习的分区函数**：
   - 定义分区函数 \( Z_\phi(x) \) 将标量奖励归一化为一个目标分布。
   - 目标分布定义为 \( \tilde{\pi}(y|x) = \frac{\exp(\beta r(x, y))}{Z_\phi(x)} \)。
   
2. **最小化逆KL散度**：
   - 最小化逆KL散度 \( D_{\text{KL}} \left( \pi_\theta(y|x) \parallel \frac{\exp(\beta r(x, y))}{Z_\phi(x)} \right) \)。
   - 这可以通过轨迹平衡损失实现，即最小化 \( \min_\theta \left( \log Z_\phi(x) + \log \pi_\theta(y|x) - \beta \hat{r}_i(x, y) - \log \pi_{\text{ref}}(y|x) \right)^2 \)。

3. **解决长链推理中的挑战**：
   - 引入长度归一化以解决梯度爆炸问题。
   - 使用重要性采样以纠正生成轨迹与当前策略之间的分布不匹配问题。

### 公式推导
1. **初始公式**：
   - 原始目标为最小化逆KL散度：
     \[
     \min_\theta D_{\text{KL}} \left( \pi_\theta(y|x) \parallel \frac{\exp(\beta r(x, y))}{Z_\phi(x)} \right)
     \]

2. **轨迹平衡损失**：
   - 根据轨迹平衡原理，上述目标可以转化为轨迹平衡损失：
     \[
     \min_\theta \left( \log Z_\phi(x) + \log \pi_\theta(y|x) - \beta \hat{r}_i(x, y) - \log \pi_{\text{ref}}(y|x) \right)^2
     \]

3. **长度归一化**：
   - 在长链推理中，引入长度归一化以稳定梯度：
     \[
     \frac{1}{|y|} \log \pi_\theta(y|x)
     \]

4. **重要性采样**：
   - 使用重要性采样以处理离策略数据：
     \[
     w = \text{clip} \left( \frac{\pi_\theta(y|x)}{\pi_{\text{old}}(y|x)}, 1-\epsilon, 1+\epsilon \right)^\text{detach}
     \]

5. **最终公式**：
   - 结合以上改进，得到FlowRL的目标函数：
     \[
     L_{\text{FlowRL}} = w \cdot \left( \log Z_\phi(x) + \frac{1}{|y|} \log \pi_\theta(y|x) - \beta \hat{r}(x, y) - \frac{1}{|y|} \log \pi_{\text{ref}}(y|x) \right)^2
     \]

## 理论结果
FlowRL通过轨迹平衡损失实现了从奖励最大化到奖励分布匹配的转变，解决了传统方法中的模式坍缩问题。理论分析表明，该方法能够有效地促进多样性的探索，并提高策略模型的泛化能力。

## 实验与证据
### 实验设置
- **数学任务**：使用DAPO收集的数据集进行训练。
- **代码任务**：使用DeepCoder的训练集。
- **模型配置**：使用Qwen-2.5-7B/32B和DeepSeek-R1-Distill-Qwen-7B作为基础模型。
- **训练配置**：数学任务使用batch size 512，代码任务使用batch size 64，学习率设为1e-6。

### 实验结果
- **数学任务**：FlowRL在六个基准测试中平均提高了10.0%（相对于GRPO）和5.1%（相对于PPO）。
- **代码任务**：FlowRL在三个基准测试中表现优于PPO和GRPO。

## 局限与批判
1. **分区函数的复杂性**：分区函数 \( Z_\phi(x) \) 的设计和训练较为复杂，需要额外的计算资源。
2. **长度归一化的适用范围**：长度归一化虽然解决了梯度爆炸问题，但在某些情况下可能会导致信息丢失。
3. **重要性采样的稳定性**：重要性采样虽然有助于处理离策略数据，但其稳定性仍需进一步验证。
4. **超参数选择**：超参数如 \( \beta \) 和 \( \epsilon \) 的选择对性能有较大影响，需要仔细调优。

## 与谁对话
- **T03**（Trajectory Balance）：FlowRL 使用了轨迹平衡原理来实现其目标分布匹配，这是基于 Trajectory Balance 中提出的轨迹级恒等式。
- **T07**（Towards Understanding GFN Training）：FlowRL 在理解 GFlowNet 训练过程中遇到的损失与分布误差之间的问题时，借鉴了该文的分析方法，以确保训练过程中的有效性。
- **T14**（GFN 等价于熵正则 RL）：FlowRL 的熵正则化方法受到了该论文中关于 GFlowNet 与熵正则化强化学习等价性的启发，进一步优化了策略模型的泛化能力。
- **T32**（何时学对分布）：FlowRL 在评估其训练目标与实际分布误差之间的关系时，参考了该论文的方法，确保其匹配奖励分布的目标能够准确反映实际效果。

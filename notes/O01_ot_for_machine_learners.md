# O01 · Optimal Transport for Machine Learners

## 一句话
这份材料详细介绍了最优传输理论及其在机器学习中的应用，涵盖了从基础概念到高级算法的广泛内容。

## 这份材料的定位
这份材料是一本关于最优传输理论及其在现代机器学习中应用的教程。它不仅提供了理论上的深度理解，还讨论了实际计算方法和应用案例，特别适合希望深入了解最优传输在机器学习中作用的研究者和从业者。

## 与 GFlowNet 研究的接口
GFlowNet 是一种用于生成模型的新型框架，其核心在于通过优化流来生成样本。最优传输理论可以为 GFlowNet 提供理论基础，特别是在如何高效地比较和生成概率分布方面。具体来说，瓦瑟斯坦距离和梯度流的概念可以帮助我们更好地理解和优化 GFlowNet 的生成过程。

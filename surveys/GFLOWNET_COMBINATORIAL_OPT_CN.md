## 1. 核心定位：为什么组合优化要用 GFlowNet

组合优化（CO）问题——TSP、CVRP、MIS、图着色、算子调度——多为 NP-hard，其解空间是被约束高度结构化的离散复合空间。GFlowNet 的定位**不是**「再造一个更快的最优求解器」，而是：

> 在解空间上学习一个与目标函数成正比的采样分布 \(P_T(x)\propto R(x)\)，从而一次性给出**多样的高质量解集**，而非单个最优解。

这条定位决定了它与三类既有方法的分工：

| 方法族 | 代表 | 输出 | 最优性 | 多样性 | 与 GFlowNet 的关系 |
|---|---|---|---|---|---|
| 精确求解器 | Gurobi、分支定界、KaMIS 精确模式 | 单个（近）最优解 + 证书 | 有保证、指数代价 | 无（只需一个最优） | GFN 无最优性证书；可作候选生成器供精确修正 / warm-start |
| 启发式 / 元启发式 | 贪心、2-opt、LKH、蚁群 ACO | 单条或少量轨迹 | 经验良好、无界 | 依算法而异（ACO 有随机性但易早熟） | GFN 可作 ACO 的**学习式信息先验**（见 GFACS） |
| 神经组合优化（NCO） | Pointer / Attention、POMO 等 RL 构造式求解器 | 期望回报最大化下的单 / 少峰策略 | 依训练 | **弱** | GFN 按 \(R\) 成比例采样，天然给**解级别**多样性 |

关键差异在最后两列。标准 RL / NCO 优化的是**轨迹级**熵或期望回报：

- 会收敛到单峰，容易陷在「可由许多轨迹到达的同一个解」上（A19 明确讨论了这一失败模式）；
- 对解的**对称性**（同一问题的多重等价最优）不敏感。

GFlowNet 以 \(P_T(x)\propto R(x)\) 为目标，追求的是**解级别**的覆盖，并因 DAG 构造天然容忍对称最优。其实用价值在于：当目标函数其实是一个**会失准的 proxy**（编译调度里 proxy makespan 与真机不一致）时，拿到一组多样近优解、再用真实指标重排，比死磕单一 proxy 最优更鲁棒——这正是 A20 的核心论证。

## 2. 关键论文线（每篇已联网核实）

### 2.1 早期奠基

**A19 — Let the Flows Tell**（NeurIPS 2023 **Spotlight**, arXiv 2305.17010；Zhang, Dai, Malkin, Courville, Bengio, Pan）

- **地位**：组合优化 GFlowNet 的奠基工作，确立「把 CO 写成逐步构造采样过程」的范式。
- **方法**：为四个 NP-hard 图问题——最大独立集（MIS）、最大团（MC）、最小支配集（MDS）、最大割（MCut）——分别设计 MDP，状态是**部分解**（已选顶点子集），动作是**合法扩展**（加入一个顶点），训练**条件 GFlowNet**（条件于图实例）。
- **技术贡献**：针对稀疏终止奖励 + 长轨迹的**长程信用分配**给出高效训练技巧。
- **隐患**：非回溯构造式策略可能退化成贪心（§5 的基准批评正打在这里）。

**A20 — Robust Scheduling with GFlowNets**（ICLR 2023, arXiv 2302.05446）

- **问题**：计算图算子调度（编译优化中的经典 NP-hard 问题），reward 取自可快速计算的 proxy makespan。
- **核心贡献**：不是刷低单点 makespan，而是**按 proxy 成比例采样一组多样候选调度、直接在目标硬件上评测**，从而对 proxy 失准鲁棒。
- **附加能力**：给出**推理期**调节多样性↔质量的手段（无需重训）；条件于计算图后可泛化到未见图。
- **意义**：是「多样解集 > 单最优解」这一定位最干净的实证（击败只出单一调度的 list scheduling、BRKGA）。

### 2.2 与经典搜索的混合（当前 SOTA 走向）

**GFACS — Ant Colony Sampling with GFlowNets**（AISTATS 2025, PMLR 258:469–477, arXiv 2403.07041；Kim, Choi, Kim, Son, Park, Bengio）

- **思路**：分层结合**摊销推断**与**并行随机搜索**。先用 GFlowNet 摊销一个条件于实例图的**多峰先验**（兼顾高回报与多样），再以蚁群（ACO）式并行随机搜索迭代更新为生成近优解的后验。
- **相对 DeepACO（神经引导 ACO 前作）的改进**：off-policy 训练可吸收任意行为策略（含强启发式搜索）产生的样本；按分布采样契合多峰性；DAG 构造天然编码解的对称性。
- **训练技巧**：search-guided 局部探索、能量归一化（shared energy normalization）、能量整形。
- **结果**：在七个 CO 任务（含 VRP、调度、分组）上超过经典 / 神经 ACO，并在 \(N=500,1000\) 大规模 TSP / CVRP 上与专用 RL 求解器竞争。是「GFN 作为可训练先验、嵌入经典元启发式」的代表。

**AGFN — Adversarial Generative Flow Network for VRP**（arXiv 2503.01931, 2025 预印本；Zhang 等）

- **地位**：首个把 GFlowNet 直接用作**端到端构造式** VRP 求解器的工作。
- **方法**：GFlowNet 作生成器（TB 目标构造多样路线），配一个判别网络区分「原始解」与「经局部搜索增强的解」，二者**对抗式交替训练**，再用 hybrid decoding 出解。
- **结果**：CVRP / TSP 上超过主流构造式神经求解器；它与 GFACS 是 T41 明确点名要增强的两条 GFN-VRP 基线。

**T41 — Hybrid-Balance GFlowNet / HBG**（NeurIPS 2025, arXiv 2510.04792；Zhang Ni, Cao Zhiguang）

- **动机**：既有 GFN-VRP 求解器（GFACS、AGFN）只用 TB 做**全局**监督、忽视**局部**优化信号；而单用 DB 又抓不住 VRP 需要的整体轨迹质量。
- **方法**：自适应统一 TB（全局）与 DB（局部）；为有 depot 的 CVRP 设计 **depot-guided 推理**——反向策略分析显示只有 depot 节点在轨迹结构中有多前驱灵活性，故只在 depot 处随机采样、客户节点用贪心，缩小无效探索。
- **形态**：作为**即插即用**模块集成进 AGFN 与 GFACS。
- **结果**：CVRP 与 TSP 上一致降低 gap；消融显示单用 DB 最差、单用 TB 尚可、HB 最好，depot-guided 再叠加收益。
- **告诫**：定位是 VRP 专用方案，不宜当作通用信用尺度组合方法（catalog T41 已如此标注）。

### 2.3 2025–2026 增量

- **Exploration through Generation**（arXiv 2510.21886, 2025 预印本）：在 TSP、最小生成树、最短路上用 TB 训练 GFN，生成解可匹配 Dijkstra / Kruskal / 精确 TSP 求解器的已知最优；属教学式验证，主张 GFN 的优势在**摊销 / 可扩展性**而非单实例胜出。
- **Exploring Multiple High-Scoring Subspaces / CMAB-GFN**（arXiv 2602.11491, 2026 预印本）：用组合多臂老虎机先剪掉低质动作、把 GFN 限制在紧凑的高分子空间上，在保多样的同时偏置高回报，缓解大状态空间过度探索。

## 3. 技术要点：如何把 CO 写成 GFlowNet

- **状态 = 部分解**：MIS 的已选顶点集、TSP / CVRP 的部分路径、调度的已定序算子序列；初始态为空解，终止态为完整可行解。
- **动作 = 合法扩展**：加入一个顶点 / 一条边 / 下一座城市 / 下一个算子。
- **约束处理（CO-GFN 与一般 GFN 最大的工程差别）**：
  - **硬约束用动作掩码**：只允许保持可行性的扩展（MIS 只能加非邻居顶点；CVRP 受容量约束掩码），从而保证终止解可行；
  - **软约束进 reward**：作为惩罚项混入奖励。
- **reward = 目标函数的能量化**：典型取 \(R(x)\propto\exp(\text{objective}(x)/T)\) 或 \(\exp(-\text{cost}(x)/T)\)；温度 / 逆温 \(\beta\) 调节分布锐度（高 \(\beta\) 偏少数最优、低 \(\beta\) 偏多样）。GFACS 的能量归一化 / 整形即在稳定这一尺度。
- **信用分配**：终止奖励稀疏 + 轨迹长导致长程信用分配困难；A19 用 flow / 局部平衡缓解，T41 显式区分并融合 TB（全局）与 DB（局部）。
- **与局部搜索 / 精确修正结合（实战关键）**，三种耦合方式：
  1. **off-policy 行为策略**：GFACS 让强局部搜索 / 启发式生成的轨迹进入训练；
  2. **判别式增强**：AGFN 用局部搜索产出的「增强解」训练判别器反哺生成器；
  3. **后处理 / 精确修正**：对采样出的多样候选做 2-opt / LKH 精修，或作精确求解器的 warm-start 与解池。
- **经验规律**：GFN 单独很少直接给出最优解，其价值在**生成一批高质量起点**交给经典搜索收尾。

## 4. 与最短路 / 最优传输的关系（对接 guide §5.5、§7.3、§8.6）

CO 的构造 DAG 本身就是一张图：GFlowNet 把概率质量从初始状态经「扩展」边路由到终止解。guide §5.5 的 2026 结构性结果——「Your GFlowNet Secretly Learns an Optimal Transport Plan」（arXiv 2606.06272，**ICML 2026 SPIGM Workshop，非主会**）——在这张图上提供了传输视角：

> 固定源边缘 \(L\)、固定目标边缘 \(R\)、以图最短路为 ground cost、取最小总流并达全局最优的**非无环** GFlowNet，其流恰好编码一个 Kantorovich OT coupling。

配套的「Learning Shortest Paths with GFlowNets」（arXiv 2603.01786, 2026 预印本）证明 minimum-flow 会选出最短构造路径。对组合优化的启示与**限定**须一并写清：

- 一般 CO-GFN（A19、GFACS）是**单源、reward-matching 的 DAG**，**并不**自动在做 OT；
- OT 等价需要同时固定源与目标两侧边缘、最小总流、最短路代价、全局最优这一整套非无环设定（guide §8.6 明确警告不能省略）；
- 传输视角真正的价值是**归纳原则**：在「许多都正确的内部流」中，minimum-flow 提供一个可优化偏好——倾向更短构造路径，同时学到 coupling 与局部路由策略。

「Exploration through Generation」把 GFN 直接用于最短路 / MST / TSP，正是这条「组合图上的流即传输」叙事的经验落点。

## 5. 评估：gap、多样性、可扩展性，以及对比是否公平

- **最优性 gap**：相对最优 / 最佳已知解的百分比偏差是首要指标（T41 消融即以 gap 汇报）；GFN 无最优性证书，报告 gap 时须同时给出采样预算（采样条数、是否 best-of-\(k\)）。
- **多样性**：解间成对距离、覆盖的不同模式数、对称最优覆盖率。但**多样性只有在解也高质量时才有意义**——单看「模式数」可被灌水刷高；A20 的做法值得效仿：把多样性绑定到「真机 / 真实指标上的鲁棒收益」而非孤立汇报。
- **可扩展性**：规模从 \(N=200\) 到 \(500 / 1000\) 的 gap 退化、wall-clock 与显存（GFACS / T41 均在此维度比较）。
- **与 OR-Tools / Gurobi / KaMIS 对比是否公平（本节最关键的警示）**：
  - 「Unrealized Expectations: Comparing AI Methods vs Classical Algorithms for MIS」（**TMLR**，arXiv 2502.03669；Wu, Zhao, Arora）系统发现：在 MIS 上，包括基于 GFlowNet 的 LTFT（即 A19）在内的 GPU 类 AI 方法，即便加局部搜索后处理，也**一致地输给单颗 CPU 上的经典求解器 KaMIS**，部分方法甚至不如最简单的度数贪心；
  - 其 serialization 分析揭示：**非回溯的构造式 GFN 推理起来近似度数贪心**，因而弱于带回溯的 KaMIS；
  - 由此得出公平对比的硬约束：(i) 对齐硬件与 wall-clock 预算（不能拿 GPU 集群比单 CPU）；(ii) 用**强**经典基线（KaMIS、LKH、带时限的 Gurobi），而非只挑弱基线；(iii) **拆分神经贡献与局部搜索贡献**——若去掉 2-opt / LKH 后处理性能大幅回落，则「胜出」主要来自经典算子而非 GFN。

## 6. 小结与开放问题

GFlowNet 在 CO 上最稳的价值主张，不是在单解最优性 gap 上击败 KaMIS / LKH / Gurobi（严格基准 TMLR 2502.03669 表明它在 MIS 上做不到），而是**产出一个校准的、覆盖近优解的多样分布**——当目标是会失准的 proxy（A20）、或下游需要多个候选 / 对称最优时才真正兑现。2025 年的 SOTA 走向（GFACS、AGFN、T41）也印证：GFN 最有竞争力的形态是**作为可训练先验 / 生成器，与经典搜索（ACO、局部搜索、TB+DB）的混合体**，而非独立端到端求解器。

开放问题：

1. 把回溯 / 精确修正原生嵌入构造过程，以突破「构造式≈贪心」的天花板；
2. 让 minimum-flow / OT 的传输原则从 workshop 结构性结果，落到可扩展的 CO 训练目标；
3. 建立强制对齐硬件与 wall-clock、区分神经与搜索贡献的公平基准协议。

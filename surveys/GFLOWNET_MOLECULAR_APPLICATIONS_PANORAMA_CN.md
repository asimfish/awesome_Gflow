结论：GFlowNet 在这条线上的独特卖点不是“搜出单个最优分子”，而是——

> 在昂贵、且几乎总是 **proxy** 的奖励下，一次性给出一批**多样、有效、可合成**的候选，并把有效性、可合成性和多目标偏好尽量写进**生成过程**本身，而不是留到事后筛选。

它已在片段图、化学反应空间、生物序列和抗体等任务上跑通；但“是否真的采到了与奖励成比例的分布”以及“proxy 奖励有没有被 reward hacking”这两件事，是最容易被 max/mean reward 曲线掩盖的软肋，也是这条应用线和纯优化方法（RL、遗传算法、贝叶斯优化）真正拉开差距的地方。

## 1. 为什么分子设计天然契合 GFlowNet

药物发现在结构上就需要“一批”而不是“一个”候选：

- 先导化合物在后续 ADMET、毒性、成药性和临床阶段流失率极高，必须保留结构不同的备选与多条作用机制；
- 类药化学空间体量常被估计在 \(10^{60}\) 量级且高度多峰，纯 argmax / 单目标 RL 往往塌缩到一个模式，牺牲专利空间和抗风险能力；
- 湿实验和高精度模拟每次评估都很贵，理性做法是提交一批多样假设、再用实验回填信息。

GFlowNet 的训练目标正是 reward-proportional 采样

\[
P^\star(x)=\frac{R(x)}{Z},
\]

因此高奖励区域会被**多样地覆盖**而不是收敛到单点，这是它相对最大化类方法的结构性优势。事实上，分子设计正是 GFlowNet 原始论文（T01）的核心动机案例；A01 则把分子、蛋白、材料、因果发现和主动学习统一成一张应用版图，是这条线的总入口综述。

### 1.1 与 RL / 遗传算法 / 贝叶斯优化 / diffusion 的分工

把 GFlowNet 放进整张分子生成版图，它的定位由“输出一批按奖励成比例的多样解”这一点决定：

| 范式 | 输出 | 在分子设计里的定位 | 主要风险 |
|---|---|---|---|
| RL（最大化奖励） | 单个/少数高分解 | 单目标、只要最优时最直接 | 模式塌缩、reward hacking |
| 遗传算法 / 贝叶斯优化 | 一批解，多样性靠显式机制 | 黑盒昂贵 oracle 下的经典强基线 | 覆盖依赖算子 / 采集函数设计 |
| Diffusion / 自回归生成 | 逼近数据分布 | 有大量数据时的强生成先验 | 难直接对齐稀有高奖励目标 |
| GFlowNet | 按 \(R(x)/Z\) 采样的一批多样解 | 奖励可评但数据稀少、且要多样候选 | 分布是否真校准、proxy 偏差被放大 |

关键是这些范式并不互斥：A08 把遗传算法经验蒸馏进 GFN，A12 借预训练/先验，A04 把 GFN 嵌进主动学习式的预算分配，现实里更多是组合使用而非二选一。

## 2. 状态与动作空间：分子怎样“逐步构造”

应用论文彼此最大的差异，在于“把什么定义成一步动作、什么时候终止、有效性约束从哪里进来”。按构造粒度可以铺成一条谱系：

| 构造粒度 | 代表工作 | 一步动作 | 有效性 / 约束如何进入 |
|---|---|---|---|
| 原子 / 片段图 | T01、A12 | 加原子、加片段、连边 | 价键 mask；有效性主要靠后处理 |
| 化学反应空间 | A09、A11 | 选反应模板 + 选可购买 reactant | 样本自带合成路径，天然可合成 |
| SMILES + 大规模先验 | A15 | 生成字符 / 子串，受先验与软约束引导 | 用 foundation SMILES 先验拉高有效率 |
| 生物序列 / 编辑 | A02、A10、A13 | 逐位构造，或在 seed 上做少量编辑 | 编辑距离、语言模型先验 |
| 几何 / 构象 | A05 | 连续坐标 / 扭转角 | 能量 oracle + 对称性，属连续 GFN |
| 晶体 / 材料（相邻） | A06、A16 | 组成、空间群、几何参数 | 结构先验、空间群约束进入 mask |

这里最重要的趋势是**可合成性从“事后筛选”前移为“生成约束”**。原子级构造（T01、A12）最灵活，但会大量生成化学无效或无法合成的分子；反应级构造（A09 Reaction-GFlowNet、A11 SynFlowNet）把动作定义在反应模板加可购买构件上，于是每个终止样本天生带一条合成路线，可合成性不再是筛子而是环境本身的约束。A15（S3-GFN）走另一条路——保留 SMILES 的灵活性，用大规模先验和软约束把有效率与可合成率拉上来。几何构象（A05）和晶体（A06、A16）把逐步构造推广到连续与周期性对象，但也把连续 GFN 的测度、对称性和能量误差问题一并带了进来。

对长分子/长序列，逐步构造会遇到长轨迹信用分配问题（参见理论线 T03 的 TB 长轨迹乘积、T30 的宏动作/动作抽象），这也是分子 GFN 训练不稳的常见根因之一。

## 3. Reward 设计：proxy、多目标与先验融合

分子任务的奖励**几乎从不是真值**：它通常是 docking 分数、QSAR/性质预测器或某个学习到的 proxy。这一点很大程度决定了这条线的成败：

- **多目标与偏好**：真实项目要同时权衡亲和力、选择性、成药性、毒性。A03 用偏好向量条件化 GFN，一次训练即可按不同 Pareto 权衡采样，避免为每组权重重训；
- **先验 / 专家乘积（product-of-experts）**：A13 把蛋白语言模型先验与效力、可开发性等多项 reward 组合成抗体设计器，是“生物先验 × 多 reward”的代表；A15 把 foundation SMILES 先验注入 GFN；
- **廉价 proxy 预训练**：A12 先用便宜 proxy reward 预训练原子级分子 GFN，再适配昂贵目标，研究 proxy 预训练何时提升样本效率、何时把偏差带入下游。

必须记住的风险：GFN 会**忠实地**采到与所给奖励成比例的分布——如果 proxy 本身有偏，它就会忠实地放大这个偏差。因此 reward 设计的错误在这条线里不会被“分布采样正确”所纠正，只会被如实执行。

## 4. 主动学习与实验闭环

当真实 oracle（湿实验或高精度模拟）很贵时，GFN 的位置是主动学习循环里的**多样候选提议器**：

- A02 把序列设计与主动学习结合，在昂贵 oracle 下反复提出一批多样高适应度候选；
- A04 进一步做**多保真**主动学习——联合决定“测哪个候选”和“用多贵的保真度测”，在低成本近似与高成本真实实验之间分配预算。

这类工作真正兑现了第 1 节的动机：一批多样候选的价值不在于每个都最优，而在于它们能高效探测假设空间、给下一轮 oracle 提供信息量最大的样本。

## 5. 探索、搜索效率与离线/局部动作

高奖励模式往往稀疏，纯 on-policy 很难快速找到，于是出现几条加速路线：

- A08 把遗传算法产生的结构化搜索经验蒸馏进 off-policy GFN，属经典启发式搜索与分布学习的混合；
- A10 从 seed 序列出发做少量、多样的编辑而非从头生成，天然贴合“改一个已知 hit”的真实场景；
- 理论侧的 Local Search GFlowNets（T23）与此同源。

共同的告诫：这些技巧提升的是**发现效率**，评估时必须同时检查分布误差，否则很容易退化成“只会冲最高 reward”的搜索器，反而丢掉 GFN 的多样性卖点。

## 6. 有效性、“泄漏”与合成可行性

真实化学环境里，大量 terminal 是无效或无法合成的，这会污染目标分布：

- A14（LeakGFN）显式区分“真正有效分子流”和因截断、无效动作产生的“泄漏”终止流，减少这种污染；
- A15（S3-GFN）直接把有效率和可合成率当作要提升的指标；
- A09 / A11 则从源头用反应空间保证可合成。

这类问题是 toy HyperGrid 完全看不到、却在分子任务里直接决定成败的现实细节。

## 7. 评估的陷阱（这一节最关键）

这条线最常见的错误是**只用最高或平均 reward 判断成败**。GFN 的正确性主张是“按 \(R(x)/Z\) 采样”，而不是“找到 max”，所以评估必须回答“分布对不对”：

- **分布保真**：只有能枚举 \(P^\star\) 的 toy/小任务才能直接测 TV/JS；真实分子任务只能用代理指标，必须说清这一点；
- **多样性与覆盖**：mode coverage、Tanimoto/scaffold 多样性、novelty，而不是 Top-1 reward；
- **有效性 / 可合成性**：有效率、SA 分数、逆合成可行性；
- **proxy 与真实 oracle 的 gap**：报告 proxy 高分候选在真实 oracle 上的命中率，检查 reward hacking；
- **相对最强基线**：与 RL、遗传算法、贝叶斯优化在**同一 oracle 预算**下比，而不是各挑各的指标。

理论侧的 correctness 诊断（T32：“loss 很低不等于分布正确”）在分子任务里尤其要记住：真实分布不可枚举，低 loss 更容易给人虚假的安全感。一个例外值得单独点名——A07（PhyloGFN）在系统发育树上有**明确的 Bayesian 后验**作为目标，属于少数“目标分布本身定义清楚”的分子相邻任务，因此比 proxy-reward 任务更适合检验 GFN 是否真的采对分布（尽管树空间仍不能完全枚举）。

一句话清单：**报告分布 / 多样性 / 有效性 / 真实命中，而不是只报一条上升的 reward 曲线。**

## 8. 现状与开放问题

诚实的成熟度判断（并守 venue 纪律）：

- **较扎实**：片段/原子图生成、反应级可合成生成（A09、A11）、多目标（A03）、主动学习闭环（A02、A04）都已在主会/期刊发表、机制清楚；
- **较新、需审慎**：晶体/材料的 A06、A16 仍是**预印本**，分布评价和对称性处理需重点核查；A14、A15 是 **ICML 2026** 主会但很新，宜等更多独立复现；
- **仍薄弱**：连续/几何构象只有 A05 一类代表，3D 与能量 oracle 误差的处理远未成熟。

开放问题：

1. **统一“可合成 + 多目标 + 3D”**：现在这三者基本是分开解决的；
2. **更稳健的 proxy 与去偏**：如何在 proxy 有偏时仍不放大偏差（与理论线 T53 的 proxy/轨迹蒸馏思路相关）；
3. **真正闭合湿实验回路**：报告真实实验命中率而非仅 proxy 分数；
4. **化学任务的分布保真基准**：目前缺少像 toy task 那样可信的分布误差评测协议；
5. **跨靶点/跨任务泛化**：能否像 foundation model 一样预训练一次、迁移到新靶标（与理论线 T22 预训练、T55 组合复用相关）。

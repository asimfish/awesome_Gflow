02GFlowNet 解决的是什么问题

不是「找最优解」，而是「按奖励比例采样多个好解」。

目标

采样而非最大化

训练一个前向策略，使终止对象 x 的采样概率满足 P(x) ∝ R(x)。当奖励有多个模态时，概率质量按比例铺开在所有高奖励模态上，而不是全部压到单个最优点。

为什么重要

药物发现要的是候选池

单个「最优分子」在湿实验里很可能失败，需要一批结构多样的高分候选。奖励最大化方法（PPO/GRPO）天然坍缩到单模态，这是结构性差异而非调参问题。

s₀ 空对象起点
→
s₁ 加一个片段动作
→
…轨迹 τ
→
x 完整分子终止态，奖励 R(x)

同一个 x 可由多条轨迹到达（合流 DAG），这正是 GFlowNet 与自回归模型的核心分野：需要流守恒约束来保证边缘分布正确。

03训练目标谱系：从局部约束到轨迹级恒等式

四代目标的核心差异在「信用信号传播多远」与「方差多大」的折中。

目标约束粒度解决什么代价编号
Flow Matching (FM)单状态入流=出流最初的正确性保证长轨迹信用传播慢T01
Detailed Balance (DB)单边不需枚举父节点比值梯度方差大T02
Trajectory Balance (TB)整条轨迹一步把终端奖励传到起点长轨迹乘积、需估 ZT03
SubTB任意子轨迹（λ 加权）在 DB 与 TB 之间连续插值终止漂移、有效性退化T05
f-TB / 散度族轨迹级，一般 f-散度把 TB 纳入更大的散度家族散度选择成为新超参T49 / T17

TB 的恒等式：Z·∏P_F(s_t|s_{t-1}) = R(x)·∏P_B(s_{t-1}|s_t)。左右取对数作差平方即为 TB loss，Z 作为可学习标量与策略联合训练。

04趋势一：目标设计从「平衡族」走向「证书族」与「博弈族」

2026 年的新论文不再只提新平衡式，而是给出可验证的保证或引入对抗机制。

证书族

Stable GFlowNets

把 TB loss 与全局 TV 误差双向打通：给出 loss→TV 上界与有限样本 TV 证书；同时反例证明「小 TV 误差不蕴含有界 loss」——后期 loss 尖峰可能是良性的。用参考流封顶 loss 比率。

arXiv 2605.01729

博弈族

DTB / ACE

训练一个探索策略专门去采样「当前 GFlowNet 低估的区域」，与主网络构成双人博弈并刻画均衡。多样高奖励区域的发现率一致超过 curiosity 驱动基线。

arXiv 2602.17827

LLM 专用

RapTB + SubM

针对 LLM-GFlowNet 的两个可复现失败模式（前缀坍缩、长度偏置），把子轨迹监督锚定在根节点、用吸收后缀回传奖励；子模回放兼顾奖励与多样性。做到 32B 规模。

arXiv 2603.00454

读法：单纯提出新平衡恒等式的窗口正在关闭，增量空间在「目标 + 可验证保证」与「目标 + 探索机制」。

压力测试

去掉熵门控后 GRPO 完全坍缩

治疗性肽生成实验：GFlowNet 的二肽采样均匀度高 5.4×、奖励方差低 1.9×、重复序列少 3.9×。去掉奖励里的熵门控后，GRPO-D 的 1000 个样本 100% 含同一三肽模式，而 GFlowNet 多样性保持 0.937。

判断

护城河不是峰值奖励，是抗奖励设计缺陷

GRPO 系要靠精调的多样性惩罚与熵门控才不坍缩，而这些超参在真实药物发现流水线里通常调不准。GRPO 综述把 diversity preservation 单列为研究方向，从反面印证这是结构性弱点。

07GFlowNet 的相对位置：不是升降，是性质变化

作为「独立方法品牌」在下降，作为「off-policy 训练目标」在上升。

下降的维度

纯采样性能与理论独立性

  • 物理场景 SOTA 已被 iDEM、力引导漂移、FP++ 占据——它们用能量/力/Jacobian 结构，GFN 的离散组合优势用不上
  • 熵正则 RL（T14）、Markov chain、OT（O08）、连续时间路径测度四个视角都能把 GFlowNet 写成特例，纯框架新颖性不再是卖点
上升的维度

目标采用度与应用护城河

  • 扩散采样器方向把 TB/VarGrad + 回放 + 局部搜索当作标准配置；torchgfn 把 off-policy 训练写进官方指南，工程已固化
  • 「奖励设计不完美仍保多样性」在分子与肽两个独立实验都有量化证据，是 GRPO/PPO 拿不出的
  • FlowRL 作为 recipe 合并进 verl（PR #3924，2025-11-06），首次进入 2 万 star 级生产训练框架

给新入场者：不要做「GFlowNet vs X 谁更强」的对比论文（结论已明确且依场景而定），要把鲁棒性优势落到具体流水线，或做 GFN×OT 这类结构性连接。

09最值得投入的方向：GFlowNet × 最优传输

这是本次调研中唯一「理论干净、抓手明确、竞争未饱和」的交叉方向。

已建立的结果

GFlowNet 隐式在解图上 OT

最小流非无环 GFlowNet 学习问题可等价写成线性规划；固定初始边流分布后，就变成以图上距离为代价的 Kantorovich OT 问题（也等价于图上 Beckmann 问题的离散形式）。最优前向策略采样的正是最优路径，诱导最优耦合。

O08 · Your GFlowNet Secretly Learns an Optimal Transport Plan

对偶方向

SB/OT 提供代价结构，GFN 提供可扩展参数化

DDSBM 把 Iterative Markovian Fitting 扩展到离散空间解 Schrödinger 桥，其动力学等价于以图编辑距离为代价的熵正则 OT。两条线在 2026 年不是替代而是收敛：SB/OT 给目标与代价，GFN 给离散组合空间的 off-policy 训练。

N043 / DDSBM · ICLR 2025

可操作抓手

三个具体切口

  • 把 O08 的 LP 等价性从「固定初始边流」放宽到一般情形，看最优耦合是否仍可由 GFlowNet 策略表示
  • 用 GFlowNet 求解大规模图 OT（精确解不可行的组合规模），与 Sinkhorn 类方法在同一图上做代价-时间曲线对比
  • 把 DDSBM 的「最小图变换」性质引入 GFlowNet 的分子优化：在保持 P(x)∝R(x) 的同时约束编辑距离

11结论与下一步

三条判断，三个动作。

判断一

理论已成熟，别再刷目标

loss→KL→TV 链条闭合、速率分层与样本复杂度都有结果。新目标要过审必须附带可验证保证或解决被命名的失败模式。

判断二

护城河是鲁棒性，不是峰值

与 GRPO 系的对比证据一致指向「抗奖励设计缺陷」。这决定了应该主打的场景是奖励函数难以精调的真实流水线。

判断三

生态薄，工程红利未被吃掉

只有 torchgfn 全指标健康、只有 verl 一个生产框架集成。做好用的工具与标准化基准，回报可能高于再发一篇方法论文。

行动项

下一步做什么

  • 攻函数逼近下的收敛性（当前唯一明确的理论空位）
  • 沿 O08 推进 GFN×OT：放宽 LP 等价性条件 + 大规模图 OT 求解器对比
  • 补齐生态：面向 LLM 后训练场景的 GFlowNet 训练库与标准评测套件
